## 项目硬约定

1. **核心逻辑零 Obsidian 依赖**：`src/core/` 不 import obsidian，保证可在 node 下单测；
   Obsidian API 只在 `src/obsidian/` 与 UI 层出现，通过接口注入。
2. **AI 永不静默写笔记**：半自动区（设置里指定的文件夹）外只出建议；写入必须经用户点击「应用」。
3. **翻译表双字典 key 必须一致**：单测强制校验 zh/en key 集合相同，缺 key 直接红。
4. **提交规范**：conventional 前缀，body 写为什么；`git commit -F <文件>`，不用 `-m`。
5. **密钥不落地**：API key 只存 Obsidian data.json（本地），不进 git、不进代码、不进日志。
