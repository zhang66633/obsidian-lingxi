# 踩坑记录

## 环境与工具链

### P1 raw.githubusercontent.com 在本机 DNS 解析到非公网 IP（2026）
- 现象：`web_fetch` 拉 GitHub raw 文件报 `resolves to a non-public IP address`
- 规避：改用 **GitHub MCP**（`mcp__github__get_file_contents`）读仓库文件，稳

### P2 firecrawl 匿名检索被拒 403（2026）
- 现象：`read_page` 内部 firecrawl 报 keyless 403，只能退化本地直取
- 规避：`read_page` 仍可用（本地引擎直取页面全文）；`firecrawl` CLI 搜索可用
  （已成功两次）。firecrawl 的 `search-feedback` 参数经 PowerShell 传 JSON 被剥引号，
  两次都报 invalid JSON——**后续要用就用 bash 风格 heredoc 或写成临时文件再传**

## 网关与 API

### P3 学校网关无 CORS 头 → 渲染层 fetch 不可用（2026）
- 现象：`Invoke-WebRequest` 探到 401 响应头无 `Access-Control-Allow-Origin`
- 结论：浏览器/fetch 路径必被 CORS 拦；Obsidian 插件内一律用 `requestUrl`
- 连带决策：v0.1 无流式输出（requestUrl 拿全量响应）

### P4 obsidian typings 版本 1.13.1 > 本机 Obsidian 1.12.7
- 现象：`npm view obsidian version` = 1.13.1，注册表显示已装 app 是 1.12.7
- 规避：minAppVersion 设 1.12.7，API 只用稳定签名（已对照 1.13.1 的 d.ts 逐类核对）

### P5 grep 工具扫 `.dsh` 目录被 node_modules 断链炸掉（2026）
- 现象：`rg` 对断符号链目录报 error 3 刷屏
- 规避：grep 范围收敛到具体文件，或用 PowerShell `Select-String` 限定 `*.json`
